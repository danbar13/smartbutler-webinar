## 🚀 פריסה ב-Vercel
1. נכנסים ל-Vercel (vercel.com) ומתחברים באמצעות חשבון ה-GitHub.
2. בוחרים **Add New...** ⬅ **Project**.
3. בוחרים במאגר `danbar13/smartbutler-webinar` ולוחצים **Import**.
4. לוחצים **Deploy**. האתר יעלה לאוויר באופן מיידי עם כתובת ייעודית (למשל `smartbutler-webinar.vercel.app`).
